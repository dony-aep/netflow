## 0.0.1

* Plugin local para acceder a Android TrafficStats desde cualquier isolate (incluido background).
* Expone estadísticas de tráfico: totalRx/Tx, mobileRx/Tx, wifiRx/Tx.
* Incluye NotificationHelper y SpeedIconGenerator para notificación con icono dinámico de velocidad.
* Canal de notificación de alerta para límite de datos (alta prioridad).
* Icono monocromático (`ic_stat_netflow`) para barra de estado.
